# ITR-3 Field-by-Field Guide — Part 1: Personal Information through Schedule HP

Literal transcription reference for the official notified ITR-3 form, AY 2026-27
(`Reference Docs by CBDT & ITD/Official ITR FORMS/ITR-3-2026-Eng.pdf`, Gazette
"Part II—Section 3(i)", printed pages 75–93 / PDF pages 1–19). Read directly from the
rendered PDF pages (not text-extracted), transcribed as printed — field labels, line-item
numbers/letters, column headers, dropdown/tick options, units, and formulas are quoted
verbatim, not paraphrased. This is a literal reference, not analysis or implementation
guidance.

**Scope of this file:** Personal Information (A1–A18) through the end of Schedule HP —
sections 1–13 of the form's own printed sequence. Schedule BP onward is a separate file.
